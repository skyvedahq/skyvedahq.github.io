Skyveda Scan

Our open-source, read-only scanner. Run it on your own subscription in minutes and get a report in rupees, plus a reviewed fix script for each finding. Nothing leaves your machine.

60checks
34/34planted flaws caught*
0changes to your cloud
Get it on GitHub Book a free walkthrough

* In our own test lab, built to test our checks. One data point, not a benchmark. Free under Apache 2.0.

# install
$ pip install "skyveda[azure]"

# scan one subscription (read-only)
$ skyveda scan --provider azure \
    --subscription <id> --out ./out --pdf

# turn findings into reviewed fixes
$ skyveda fixes ./out/findings.json --out ./fixes
✓ 23 fix scripts written, every command commented out
